# Plan: Fix the label attractors (and correct the record)

## Problem

The task began as "curate the seed `task-taxonomy.json`, which contradicts the prompt's own
avoid-list." Investigation changed the target.

### What is actually true

1. **The seed does contradict the prompt.** `skills/revenium/task-taxonomy.json` ships
   `research, analysis, generation, review, code_review, refactor, planning, debugging`;
   `_build_classification_prompt` says *"AVOID bland catch-all labels like generation,
   analysis, review, task"*. Three of the four named words are shipped seed labels.

2. **It is drift, not a live decision.** The seed shipped 2026-05-12 (`8fc8e3c`, "8 labels in
   D-06 order"). The mint-first prompt rewrite that introduced the avoid-list landed
   2026-05-14 (`3fcdd58`), two days later. The seed has been modified exactly once — the commit
   that created it. The Phase 2 decision record is pruned from the working tree; only the
   commit survives, and it records the order, not the rationale.

3. **My spike-003 attribution was wrong, and it is published.** Spike 003 reported that a
   CI-flakiness item drew `sql_query_debug` and a security review drew `prod_log_triage`,
   calling both "seeded generic labels". Neither is a seed label. Both are among the five
   hardcoded *"Good examples"* in the prompt string (`classifier.py:787`:
   `weekly_pr_review, prod_log_triage, news_summary, sql_query_debug, release_notes_draft`).
   The model copied its own few-shot examples verbatim. `code_review`, which the same item also
   drew, *is* a seed label — so seed reuse is real, but it was not the vivid failure.

   This wrong claim is in open PR #42, in `.planning/spikes/003-taxonomy-drift/README.md`,
   `MANIFEST.md`, `WRAP-UP-SUMMARY.md`, and the wrapped skill's
   `references/taxonomy-governance.md` and `SKILL.md`.

### Decision gate (2×2, run before writing any fix)

`seed_attractor_experiment.py` separates the two attractors — seed present/absent ×
prompt-examples present/absent, five unrelated work items per cell, outcome bucketed by exact
string identity (`seed_verbatim` / `example_verbatim` / `minted`), so no judgement call enters
the measurement.

N=1 result: baseline 2/5 example-copying (reproducing spike 003's exact two failures), **0/5
seed reuse in every arm**. Replicating at N=3 before acting — premature attribution is the
error being corrected here, and repeating it would be worse than the original.
